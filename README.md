
# Expense Tracker

A simple and responsive expense tracker built with HTML, CSS, and JavaScript.

Track daily expenses, view monthly spending, and manage your expenses in one place.

## Live Demo

[Open Expense Tracker](https://manan0807.github.io/mini-expense-tracker/)

## Features

- Add expenses with name, amount, category, and date
- View expenses by day or month
- Automatically calculate total spending
- Edit and delete expense entries
- Save expenses using browser localStorage
- Responsive interface for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/manan0807/mini-expense-tracker.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies are required.

## Data Storage

Expenses are stored in the browser's localStorage. Data is specific to the browser and device and is not synced across devices.
